# Pokebot3DS-CFW
POKEBOT3DS-CFW is a Pokémon Alpha Sapphire shiny-hunting bot built around a customised Nexus3DS CFW. It uses a read-only RAM bridge for authoritative PK6/shiny detection, InputRedirection for controller input, optional code.ips reset routing, and a native Qt desktop dashboard. Currently validated for English-language Pokémon Alpha Sapphire only.
